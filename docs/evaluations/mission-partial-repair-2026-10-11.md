# 미션 부분 수정 실제 API 비용 비교 — 2026-10-11

인위적인 설명 길이 오류에서 **부분 수정의 평균 재시도 비용은 69.9% 감소**했다.
같은 최초 생성 비용을 양쪽에 더한 **환산 총원가는 41.1% 감소**했다.
운영 월 비용 절감률이 아니라, 아래 고정 조건에서 관찰한 평가 결과다.
부분 수정은 평가용 프로토타입으로만 구현했으며 운영 서비스·키·설정·DB는 변경하지 않았다.

## 조건과 계산 범위

- 영어 회화 / 체중 감량 / 투자 가상 목표 3개, 과거 미션 목록 없음.
- 이전 평가에서 최초 호출에 코드 검증을 통과한 가상 결과를 고정 시드로 재사용했다.
  `src/test/resources/evaluation/mission-partial-repair-seeds.json`에 원본 후보와 당시 단일 호출 비용을 포함했다.
- 15개 중 설명 길이 오류 1/3/5개 × 목표별 2회 반복 = 18쌍, 방식별 18작업.
  오류는 기존 설명에 긴 문구를 붙여 주입했다. 반복은 새로운 사용자·새로운 최초 생성 표본이 아니다.
- 양쪽에 동일 목표·상황·오류 조건을 사용하고 요청 순서는 쌍마다 번갈아 배치했다.
- 전체 재생성은 운영 baseline처럼 같은 기존 요청으로 15개를 새로 생성했다.
  부분 수정은 정상 후보 제목·난이도와 실패 후보 전체 필드·오류를 추가 입력하고 수정 대상만 출력했다.
- 같은 모델 `gpt-5.4-mini-2026-03-17`, tier `default`, 출력 상한 4096, 최대 재시도 2회.
  부분 수정의 시스템 안내는 기존 설계 기준을 유지하며 출력 형식만 패치 형식으로 명시했다.
- 부분 수정은 정상 후보를 서버에서 유지하고 요청 id 누락·중복·추가 및 난이도 변경을 거부한다.
  병합 후 15개 전체에 난이도별 5개·길이·문법 검증을 다시 실행했다.
- 재시도 비용은 모든 실제 호출의 입력·캐시·출력 비용을 합산했다. 실패한 호출의 비용도 포함했다.
  비용 미확인·토큰 사용량 미확인·캐시 입력 미확인 호출은 모두 0회다.
- 환산 총원가는 **이번 재시도 비용 + 이전 단일 최초 호출 비용**이다. 이번에 최초 생성부터
  독립 실행한 전체 작업 비용이 아니다. 초기 시드는 이미 유효했고 길이 오류는 인위적으로 주입했다.
- [OpenAI 공식 가격](https://developers.openai.com/api/docs/models/gpt-5.4-mini)의 일반 입력 USD 0.75 /
  캐시 입력 USD 0.075 / 출력 USD 4.50(각 100만 토큰당)을 사용했다. 청구액이 아닌 usage 기반 추정이다.

기존 실패 사유 실험 16회/USD 0.05334765와 합친 두 단계의 누적 실제 호출은 61회/USD 0.16572345다.

## 비교의 한계와 품질

- **양쪽 모두 통과한 14쌍만 비교해도** 재시도 비용은 69.3%, 환산 총원가는 39.4% 감소했다.
  이는 성공한 쌍만 사후 선택한 보조 지표이며 전체 성공률 추정이나 독립 검증을 대체하지 않는다.
- 캐시 할인 없이 모든 입력을 일반 단가로 재계산하면 재시도 비용은 48.7% 감소한다.
  실제 과금 비용이 아닌 민감도 비교다. 캐시·실행 순서·작은 표본의 영향은 여전히 남아 있다.
- 부분 수정 18건 모두 최초 정상 후보를 그대로 유지했다. 최종 후보에서 정확히 같은 제목은 양쪽 모두 0건이었다.
  의미 중복까지 검증한 것은 아니다. 목표 적합성·방법의 명확성도 기존 코드 검증만으로 보장되지 않는다.
- 부분 수정도 운동 목표의 5개 실패 조건 1건에서는 2회 수정 후 길이 검증을 통과하지 못했다.
  미통과·fallback 후보를 성공으로 집계하지 않았다. 전체 재생성은 4건 미통과였다.
- 수동 표본 검토에서 영어 수정 후보는 체크인·주문 연습 행동을 유지했으나, 투자 후보에는 수치 전사와
  수익률 합계 계산 등 목표 적합성·계산 방법을 추가 검토할 항목이 남아 있다.
  부분 수정은 기존 검증을 통과했지만 의미 품질이 낮은 정상 후보도 그대로 보존한다.
- 이번 비교는 설명 길이 오류·유효한 난이도 분포·빈 과거 목록에 한정된다. JSON 파싱 실패,
  난이도 분포 실패, 과거 미션 중복, 긴 입력, 실제 실패 수 분포 및 운영 전체 호출을 평가하지 않았다.
  따라서 **월 OpenAI 지출이 41% 또는 70% 줄어든다는 뜻이 아니다.**

## 적용 판단과 재현

부분 수정은 실제 비용 절감 가능성이 확인된 **후속 구현 후보**다. 운영 활성화는 하지 않았다.
다음은 실제 실패 응답·과거 미션이 있는 재추천으로 표본을 늘리고, 목표 적합성과 의미 중복을 검토한 뒤
오류 유형별 부분 수정/전체 재생성 경로와 기존 시도 상한·fallback을 보존하는 운영 코드를 구현하는 순서다.
